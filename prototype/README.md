# 臺北進行式｜開場與時間簾幕原型

這個原型只用來驗證兩件事：開場的第一眼效果，以及「上任那天 ↔ 今天」時間簾幕的互動手感。

開場約 17 秒：前 9 秒是寫實夜景的時間快轉；9–13 秒從市政府擴散一道光波，城市逐區變成白天的模擬城市風格，同時用推軌變焦把透視壓平成接近等角的遊戲視角；最後在遊戲風格裡展開松山的願景藍圖。探索模式預設為模擬城市風格，介面上的「寫實夜景／模擬城市」按鈕可以隨時切換。

## 執行

```bash
npm install
npm run dev
```

開啟 http://localhost:5173 。

| 網址參數 | 作用 |
|---|---|
| `?skip` | 跳過開場，直接進入探索 |
| `?t=5` | 把開場停在第 5 秒（調整運鏡用） |
| `?quality=medium` | 強制使用手機畫質（建築較少、解析度較低） |

`npm run data` 會重新下載原始資料並產生 `public/data/`。`public/data/` 已經附上處理好的檔案，一般開發不需要重跑。

| 東環段路線、北士科建物、松山 AI 園區分區 | 依公開描述繪製 | **示意**，卡片上已標示 |

## 程式結構

- `src/main.js`：啟動程式、狀態、相機、主迴圈
- `src/opening.js`：開場運鏡關鍵影格和日期曲線
- `src/post.js`：時間簾幕（同一畫面在兩個日期各算一次再切開）、bloom、移軸景深
- `src/layers.js`：各政策圖層，依日期決定外觀：起點→做到了→正在做→接下來
- `src/policies.js`：政策內容與來源，改文字只要改這裡
- `src/terrain.js`、`water.js`、`city.js`、`sky.js`：寫實夜景的地形、水域、城市、天空與光線
- `src/game.js`：模擬城市風格的建築（五種造型）、行道樹與山林、街道、車流、雲影；只在轉場光波內顯示
- `scripts/`：資料下載與壓縮
